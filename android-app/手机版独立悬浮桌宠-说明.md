# 深深桌宠 · 手机独立悬浮版（0.6.3）

基于 [MerZlin/dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop)（MIT）改造的个人定制版。
与你在 dsh 应用里装的网页版桌宠插件（`dsh-pet-mobile`）**完全独立、互不影响**，两个可以同时用。

## 这是什么

一个**独立安装的安卓应用**：宠物悬浮在**所有应用上层**（包括桌面、游戏、视频），永远置顶，
后台运行时不消失。锁屏自动隐藏、解锁恢复。不需要 dsh、不需要登录、不常驻联网。

## 与 dsh 插件版的关系（并存，不冲突）

| | dsh 插件版（dsh-pet-mobile） | 本应用（独立悬浮版） |
|---|---|---|
| 存在形式 | dsh 应用内网页 | 独立 APK，系统级悬浮窗 |
| 活动范围 | 只在 dsh 界面里 | 整个屏幕、所有应用之上 |
| 需要 dsh 吗 | 需要 | **不需要** |
| 动画素材 | 全部随插件打包 | 7 段随包，其余 99 段按需下载（可一键全下） |
| AI 对话 | 走 dsh 的模型配置 | 自己填 API Key |
| 数据 | 互不相通（各自记各自的设置与对话） | |

**用户自行选择**：只装插件、只装 App、两个都装都行。删掉其中一个，另一个照常工作。

## 安装

1. 把 `dsh-pet-android-0.6.3-debug.apk` 传到手机（微信/QQ/网盘均可），点击安装，允许「未知来源」。
2. 打开「深深桌宠」→ 点「允许悬浮显示」→ 系统页面授予「显示在其他应用上层」。
3. 返回应用 → 点「启动」。Android 13+ 会请求通知权限（拒绝也能用）。

覆盖升级（同一签名）不丢设置。**不要**和原作者的 0.2.1 版混装（包名相同会互相覆盖，先卸载旧的）。

## 功能清单

- **106 段动画全部可用**：安装包自带 7 段核心动画，其余 99 段（小动作、吃东西、时节、工作状态…）
  **在用到时自动下载**并存在手机里，也可以设置里一键全下。下载下来的和自带的画质完全一样（不再二次压缩）。
- **长按菜单 → 动作 → 分类 → 点播**：和插件版同一套菜单，按分类列出全部动画名，
  点哪个就播哪个；还没下载的会标「待下载」，点了先下载再播。
- **对话**：长按 → 对话，宠物旁边弹出**小气泡输入框**，输入后回复**直接显示在宠物的气泡里**——
  和插件版一样，是"在跟宠物说话"，不是一个全屏聊天页。
- **语音模式（0.6.1 改版）**：打开后，深深**气泡里出现的每一句话都会读出来**——
  打字聊天、语音聊天、点它说话、余额播报都算，不用管你是哪种输入方式。
  识别与朗读全部离线：不联网、不额外耗 API 额度；对话本身仍走你配置的接口。
  0.6.3 起，带台词的动作（点它的回应、几个自言自语的动作）说的话同样会被读出来。
- **语音输入（独立开关）**：打开后宠物旁边一直有「按住说话」圆形按钮，跟着宠物走；
  按住说话、松手发送，你说的内容边说边转成文字（中英混合）。点按钮外的任意位置可收起，
  长按菜单「语音输入」再叫回来。首次使用需授予「麦克风」权限并下载识别模型（约 50 MB）。
- **三种朗读音色（0.6.1）**：甜甜（默认女声，约 140 MB）、小雅（清亮女声，约 21 MB）、
  超文（沉稳男声，约 21 MB），设置页可直接**试听**；换音色后第一次使用自动下载对应模型。
- **查看余额**：长按 → 查看余额（DeepSeek 官方接口支持；其它接口会明确说明不支持）。
- **位置无边界**：可以把它拖到屏幕任意位置：左右、下方都允许**靠边露半身**；
  只有顶部有限制（强制显示全身，免得脑袋和气泡被切掉）。甩出去也一样，会停在边缘而不是弹回来。
- 点击 Q 弹 + 音效、拖动、快速甩动抛掷、自主游走、碎碎念气泡、
  最多 4 只小鲸鱼（会互相碰撞挤开）、大小调节、暂停/继续。

## AI 对话配置（一次性）

设置页「AI 对话」区块：

| 字段 | 说明 | 示例 |
|---|---|---|
| 接口地址 | OpenAI 兼容地址 | `https://api.deepseek.com`（默认，含 /v1 与否都认） |
| API Key | 你的密钥，只存本机 | DeepSeek 平台申请 |
| 模型 | 对话用的模型 | `deepseek-chat`（默认） |
| 人设 | 系统提示词，留空用默认女仆人设 | 自由发挥 |
| 记忆轮数 | 发给模型的上下文轮数（0=不记） | 5（默认） |

任何 OpenAI 兼容服务都能用（DeepSeek、硅基流动、OpenRouter、本地 Ollama 等，本地 http:// 局域网地址也放行）。
**不开启对话、不发消息、不下载动画时，应用零网络请求。**

对话记忆保存在运行中的应用里（聊天页可清空记忆），桌面插件那边的记忆与此无关。

## 动画素材（为什么包这么小）

- 完整 106 段逐帧素材共约 430 MB，塞进 APK 会让安装包变成 450 MB。
- 现在：**APK 只带 7 段核心动画（约 30 MB 安装包）**，其余每段一个 zip 放在
  [dsh-Jpet-phone-assets](https://github.com/Jcnet-9527/dsh-Jpet-phone-assets)，
  App 通过 CDN 按需下载、解压到手机私有目录，之后直接从磁盘解码。
- 设置 → **动画素材** 可以看到已下载数量、占用空间，一键「下载全部动作」、
  「清除已下载」，也可以把「下载源」改成自己的镜像/自建服务器（保持 `clips/<id>.zip` 结构即可）。

## 已知取舍（如实说明）

1. **首次用到新动作需要下载**：约 4 MB 一段，Wi-Fi 下 1–2 秒；移动网络会照下（没做 Wi-Fi 限制）。
2. **动画画质**：帧图是 Q80 有损 WebP（无损全量约 1 GB 装不下）。在手机 ~300px 的显示尺寸下肉眼基本无差。
3. **宽幅动作的临时盒子**：像「蝴蝶蜜蜂环绕」「吹气球」「放烟花」这类铺满画布的动效已挪到
   「特效」分类，**只在点播时播放**（不再随机出现），播放时用一块更大的舞台绘制
   （内容本身就这么宽），放完自动回到日常舞台。0.6.1 修掉了此前"新动画和旧画面对叠"的问题：
   特效播放期间主窗口停止绘制但保留触摸，不会再出现两个深深。
4. **毛玻璃视系统而定**：Android 12+ 才做窗口级背景模糊，且部分国产 ROM 对第三方悬浮窗
   不生效；不生效时自动退回半透明卡片，观感一致。
5. **未做真机验证**：构建通过了单元测试与静态检查，但手势/对话/余额/气泡输入框的实机表现需要你装上后反馈。
6. 对话消耗你自己的 API 额度，按 token 计费。

## 0.6.3 改了什么

1. **能自己检查更新了**：设置页底部「检查更新」，启动时也会静默查一次（6 小时内最多一次，
   没网不打扰）。发现新版弹窗，选「立即更新」跳到下载页，选「稍后」一天内不再自动提示。
2. **内置台词全部删除**：「好女孩……」「好模型……」那五句没了。现在 10 个动作各带一句台词
   （点击回应的五种 + 深度思考/发呆/对屏/擦桌/吃什么），动作一播台词就上气泡，开语音模式会读出来。
3. **默认人设换成小鲸鱼**：原来默认是「蓝发小女仆」，可素材全是鲸鱼尾巴、蓝鲸现世、吃 Token，
   说话还自称「本鱼」。新版默认人设是傲娇嘴硬的 DeepSeek 小鲸鱼，每句 10–40 字，
   明确说清「没有联网能力」。自己改过人设的不受影响，想回默认点「恢复默认人设」。
4. **余额能显示数字了**：以前固定提示「余额查询成功，但接口没给出数字」——接口给的是数组，
   代码按对象读。现在显示「余额 ¥110.00（赠金 ¥10.00 · 充值 ¥100.00）」。

## 本分支（0.6.3-dsh.31）相对上游 0.6.3 的差别

1. **动作台词接了，口吻换成「深深」**：10 个动作的台词不再自称「本鱼」，改成深深的口吻；
   动作一播台词就上气泡，开语音模式会一起读出来。
2. **多了一个「点它时说预设台词」开关**（设置 → 互动 → 台词，默认开）：
   - 开：点击回应秒出动画自带的那句台词；
   - 关：交给 DSH 生成一句（每次不同，需要 DSH 可达；没开 DSH 或请求失败会退回台词池）。
3. **内置 5 句台词池保留**（上游 0.6.3 把它删空了）：DSH 碎碎念和自定义台词仍然能用；
   带台词的动作播放时池子让路，不会两个气泡抢地方。
4. **没有采用上游的两项**：内置「检查更新」（它指向上游仓库，我们的版本号是 `0.6.3-dsh.N`，
   照搬会一直误报新版本，且点更新装的是另一个包名的上游 App）；小鲸鱼人设（保留「深深」）。
5. **余额修复随上游同步**：关掉 DSH 联动时，`/user/balance` 的数组也能正确显示金额了。
6. **第四个音色 melo**（0.6.3-dsh.21）：44.1k、int8，中英混读最自然；第一次选用要下载约 45 MB
   （3 个分卷，来自我们自己的 `dsh-Jpet-voice` 仓库），并花约 20 秒准备。
7. **扒在两侧**（0.6.3-dsh.30）：隔一会儿（默认 4 分钟，可在「设置 → 互动」改成 1–15 分钟）
   桌宠会从底部爬到屏幕左或右侧，默认露出小半只身子挂在中间高度，过 30–90 秒松手掉回桌面；
   觉得露太少，把「露出多少」滑杆往右拉（30%–65%，默认 45%）就能看见更多身子。
   拖动它就当没挂住，挂墙上点击也照常说话，小鲸鱼不参与。挂墙时「按住说话」按钮会自动收起。

## 0.6.2 修了什么

1. **特效不再偏透明**：特效以前画在第二个「可穿透触摸」的窗口里，Android 12 起会对这类
   窗口限制不透明度（上限约 80%），看起来就像蒙了一层。现在特效和普通动作画在同一个窗口，
   透明度完全一致。
2. **长按菜单滚动不再外溢**：圆角卡片的背景以前画在滚动容器自己身上、裁剪不了子内容，
   滚动时文字会冲出圆角；背景挪到独立容器并开启圆角裁剪，文字始终待在卡片内。
3. **AI 回答不再"查一下就没下文"**：回复以前被气泡硬截断到 90 字，加上人设会让它说
   "我去查一下"就收尾（实际没有联网能力）。现在完整回答按句子分批在气泡里依次显示、
   语音整段朗读、全文进聊天记录；请求加了 max_tokens 并检查截断标记；人设改为明确
   "没有联网能力，实时信息直说看不到"。
4. **修复关语音模式闪退**：以前在主线程直接释放正在朗读/识别的本地引擎，撞上正在跑的
   合成线程就是崩溃（这也解释了"先暂停再关就不崩"）。现在关停挪到后台线程、先等播放线程
   离开引擎再释放，同时消除了主线程等录音的卡顿隐患。

## 0.6.1 修了什么

1. **特效动画不再重叠**：0.5.1 点「特效」时会新开一个窗口播特效，而原窗口的旧画面没有被清掉
   （清空调用被当成"这一帧还没解码"直接忽略了），于是两个动画叠在一起。现在特效播放期间
   主窗口停止绘制、保留触摸，特效结束自动恢复。
2. **语音模式＝朗读所有气泡**：不再是"问一句答一句"，打字聊天也会读；点它说话的碎碎念、
   余额播报同样会读。录音中的实时转写不会被念出来（避免回声）。
3. **麦克风按钮常驻**：语音输入打开后按钮一直在宠物旁跟随移动，点按钮外可收起，
   长按菜单「语音输入」再打开。
4. **三种音色**：甜甜 / 小雅 / 超文，可在设置里切换并试听。

## 0.6.0 加了什么

1. **语音对话**：按住说话 → 本地识别 → DeepSeek → 回复气泡 + 本地朗读，一条链路全部打通。
   识别引擎是 sherpa-onnx 的流式中英双语 zipformer（int8，约 50 MB），边说边出字；
   朗读是 matcha 中文女声 + vocos 声码器（约 140 MB），自带数字/日期/多音字正音。
   两者都存在手机里、离线运行，设置里可以删除重下。
2. **设置页新增「语音对话」区块**：功能开关、朗读开关、语速（0.5~2 倍）、语音模型下载/删除。
3. 麦克风权限只在按住说话时使用；不开启语音输入则完全不碰麦克风。

（0.5.1 修复了 0.5.0 的拖拽断流与切动作闪跳：拖拽挂全屏抓取窗、窗口固定为日常舞台盒、
特效动画挪出随机池、触摸命中 9 点采样。）
